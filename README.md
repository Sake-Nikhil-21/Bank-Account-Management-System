# Bank Account Management System

## Overview

The Bank Account Management System is a DBMS mini project developed using SQL. It is designed to manage customer details, bank accounts, transactions and other banking operations efficiently.

## Objectives

- To maintain customer information.
- To manage bank account details.
- To record deposits and withdrawals.
- To perform banking transactions.
- To demonstrate important SQL and DBMS concepts.

## Features

- Customer management
- Account management
- Deposit and withdrawal transactions
- Balance management
- SQL queries and CRUD operations
- Joins and functions
- Stored procedures
- Triggers
- Views
- Transactions
- Constraints and indexes

## Technologies Used

- SQL
- Relational Database Management System (RDBMS)
- GitHub

## Project Structure

- `create_tables.sql` – Creates the required database tables.
- `insert_data.sql` – Inserts sample records.
- `constraints.sql` – Defines database constraints.
- `basic_queries.sql` – Contains basic SQL queries.
- `crud_operations.sql` – Demonstrates CRUD operations.
- `joins.sql` – Contains SQL join queries.
- `functions.sql` – Demonstrates SQL functions.
- `procedures.sql` – Contains stored procedures.
- `triggers.sql` – Contains database triggers.
- `transactions.sql` – Demonstrates transaction operations.
- `views.sql` – Creates database views.
- `indexes.sql` – Demonstrates indexes.

## Conclusion

This project demonstrates how a Bank Account Management System can be implemented using SQL and various DBMS concepts. It provides a structured way to store and manage banking information and perform common database operations.
